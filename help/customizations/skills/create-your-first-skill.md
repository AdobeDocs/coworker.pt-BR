# Crie sua primeira habilidade no Colaborador

Neste vídeo, você verá como um analista de varejo usa o Colaborador e o Customer Journey Analytics (CJA) para preparar um resumo executivo de desempenho de negócios em um prazo apertado.
 
Em vez de criar relatórios e interpretar métricas manualmente, o analista trabalha com o Colaborador para:

- Mapear perguntas comerciais para KPIs disponíveis
- Validar cobertura de relatórios
- Identificar lacunas nas métricas disponíveis
- Gerar relatórios prontos para o executivo
- Interprete os resultados e resuma as principais conclusões
- Converter a análise em uma habilidade reutilizável

O resultado é um fluxo de trabalho repetível que pode ser executado sob demanda com um prompt simples.

>[!VIDEO](https://video.tv.adobe.com/v/3502323/?learn=on&enablevpops)

## Transformar a análise em uma habilidade reutilizável

Em vez de salvar uma única resposta, o analista solicita ao Colaborador que salve a metodologia usada para criar a análise.

O colaborador reconhece o padrão recorrente, extrai o fluxo de trabalho e cria uma habilidade reutilizável que pode ser executada novamente no futuro.

## Configurar intervalos de tempo dinâmicos

Como o relatório de desempenho acontece todo mês, o analista configura a habilidade para usar intervalos de datas dinâmicos. Isso permite que execuções futuras analisem automaticamente os períodos de relatório mais relevantes sem exigir atualizações manuais.

## Publicar e refinar

Depois de revisar a habilidade gerada, o analista a publica para uso futuro. A habilidade pode ser refinada posteriormente para resolver lacunas de KPI ou dar suporte a perguntas comerciais adicionais à medida que os requisitos de relatório evoluem.
